VergeSlim

An electron-vue Verge Currency desktop wallet with Tor built in

Browse releases Source code

Current desktop version: v26.9

Features

Tor Built In

Tor has been directly integrated into VergeSlim. No worries about your privacy.

Multiple Wallets

Easily create and manage multiple wallets inside just one useful app.

Super Fast

Sending and receiving transactions is super fast and super easy.

Import & Export

Easily import and export your wallets into VergeSlim for some extra comfort.

Multiple Languages

VergeSlim supports many different languages translated by community users.

Familiar World Currencies

Display in familiar world currencies like EUR or CAD while transacting with XVG.

Windows, macOS and Linux

Install VergeSlim on Windows, macOS or Linux with the same privacy-first experience.

Very Small

No blockchain needs to be downloaded, so no syncing, no waiting, only a small app.

VergeSlim is based on MyVergies by Swen van Zanten
